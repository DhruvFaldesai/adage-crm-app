Internal tool · Adage Automation

A read‑only intelligence layer over Odoo CRM

ADAGE CRM Intelligence is a small React dashboard that sits in front of an existing Odoo CRM instance. It doesn't replace Odoo as the system of record — it re‑reads opportunities and site‑visit engagement logs and turns them into four purpose‑built views for sales leadership: a working pipeline, a visit tracker, a team activity board, and a per‑lead prospect‑health score — across regions spanning North, South, East, West, and export accounts.

Architecture

Odoo stays the source of truth

The app never talks to Odoo directly from the browser. A thin proxy holds the credentials server‑side and forwards JSON‑RPC calls, so the dashboard is safe to deploy publicly without ever shipping an API key to the client.

Domain logic spotlight

The prospect‑health score

The single most bespoke piece of logic in the app. Odoo computes a raw tier per lead from closing‑date proximity plus activity state; the dashboard turns that tier into a gauge, a colored tag with a reason, and a filtered‑set aggregate.

Color always follows the health tier; the label text follows the tier plus hasCompletedActivity() — so "Between Poor and Average" with no logged activity reads identically in color to the version with a completed call, but the sentence next to it changes. This replaced an earlier per‑row speedometer gauge (kept only in the aggregate header card above) because a full gauge per list row was too heavy for a scanning list.
